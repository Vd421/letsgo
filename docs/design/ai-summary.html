Notes for frontend-dev

  1. The AI tab replaces the placeholder in Inspector.tsx. Everything sits in a .ai panel (padding 4px, max-height 560px, scrolls like Moments).
  2. State comes from GET /config/ai + GET /sessions/{id}/analysis: not configured → "Not set up"; 404 → "Not analysed"; then queued / running / done / failed.
  3. Severity uses a label plus a 3-bar meter (never colour alone): high = filled orange-red, medium = outlined orange-red, low = grey. Sort high → low, then by time.
  4. "Jump to" calls the existing onSeek(atMs) and marks that bug row with aria-current="true" (violet ring). No button when atMs is null: show "no time" in mono instead.
  5. Tab label: "AI" + orange count when bugs > 0, or a pulsing violet dot while queued/running. Nothing extra otherwise.
  6. Sessions: new "AI" column. aiStatus null → "—"; done with bugs → orange "AI · N bugs"; done, 0 bugs → violet "AI · no bugs"; queued/running → grey "AI · analysing" with dot; failed → grey "AI · failed". Chip "AI flagged" = aiBugCount > 0.
  7. Live regions: the AI panel body has aria-live="polite" so screen readers hear "Analysis done, 2 possible bugs". The progress bar has role="progressbar" with no value (indeterminate) and an aria-label.
