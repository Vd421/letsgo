## Concepts in plain English

### Databases
- **Database** = a filing cabinet that never forgets. **Table** = one drawer (Sessions).
  **Row** = one folder (one session). **Column** = a label every folder has (`url`, `eventCount`).
- **SQL** = the database's own language, e.g. `SELECT * FROM "Session";`.
- **Prisma (an ORM)** = a translator between TypeScript and SQL: `prisma.session.findMany()`.
- **Schema** = the blueprint of the tables.
- **Migration** = a saved building instruction (SQL) for each change to the blueprint.
  Like git commits, but for the database: small, saved, in order, and replayable on any computer.
- **`?` (optional)** = the column can be empty. `endedAt?` is empty while a session is still going.
- **`@default(...)`** = filled in automatically: `uuid()` (random ID), `now()` (current time), `0`.
- **`@id` / primary key** = the unique ID of each row.
- **Generated client** (`src/generated/`) = code Prisma writes for me. It's git-ignored and recreated
  on `npm install`, like `node_modules`.

### Prisma functions
| Want to...          | Function                              |
| ------------------- | ------------------------------------- |
| get all rows        | `findMany()`                          |
| get one row by id   | `findUnique({ where: { id } })`       |
| add a row           | `create({ data })`                    |
| count rows          | `count()`                             |
| remove a row        | `delete({ where: { id } })`           |

(`push` is different: it adds an item to a JavaScript list, and `git push` uploads commits.)

### APIs
- **HTTP methods (verbs)**: **GET** = "give me something". **POST** = "here's something new, save it".
- **REST** = the address names the thing (`/sessions`), and the verb says the action.
- **Request body** = the data sent with a POST (the letter inside the envelope), usually JSON.
- `express.json()` = lets the server read JSON bodies (`req.body`).
- **Router** = a group of related routes in its own file. `app.use("/sessions", sessionsRouter)`
  means that `"/"` inside the router is `/sessions`.
- **`await`** = wait for a slow thing (like the database) to answer before carrying on.
- **Status codes**: `200` OK, `201` Created, `400` Bad data, `404` Not found.

### Zod = the bouncer 🚪
Never trust incoming data. Zod checks it against rules before it reaches the database:
- `url` must exist and be a real web address.
- `userAgent` is optional text (max 500 characters).
- If a rule is broken: reply `400` saying which field is wrong and why.

## Revision quiz answers
1. **Commit vs branch**: a commit = a permanent snapshot (the data). A branch = a pointer to a commit.
2. **After merging a PR on GitHub**: `git switch main` then `git pull` (the merge happened on GitHub, not on my laptop).
3. **Image vs container**: image = recipe. Container = a running copy of it.
4. **Redis data survived a restart**: it's stored in a Docker **volume**, outside the container.
5. **"Cannot GET /users"**: the server works, but there's no route there. Status `404`.
6. **Real API key**: it goes in `.env` (git-ignored). `.env.example` gets the name only, left blank.
