## Concepts in plain English

- **CLAUDE.md**: Claude forgets between chats; this file is its memory of the project.
- **Commit**: a saved snapshot of the project.
- **`git add`**: puts changes in the **staging area** (the list for the next commit).
- **`git status` symbols**: `??` = untracked (git sees it, not saving it), `M` = modified, `D` = deleted.
- **Remote / `origin`**: the copy of the repo on GitHub. `origin` is its nickname.
- **Node.js vs npm**: Node = the engine that runs JavaScript. npm = the "app store" that downloads packages.
- **Package**: ready-made code someone else wrote (e.g. Express).
- **devDependency**: a package only needed while developing (e.g. TypeScript, ESLint).
- **`package-lock.json`**: records the *exact* version of every package, so every computer installs the same.
- **Monorepo / workspaces**: many apps in one repo, one `npm install` for all.
- **`.gitignore` `!` rule**: `!.env.example` means "except this file". The last matching rule wins.
- **LF vs CRLF**: invisible line-ending characters. Windows uses CRLF, everything else uses LF.

## Commands learned

```bash
git status                 # what's changed?
git add <file>             # stage a change
git commit -m "message"    # save a snapshot
git push                   # upload commits to GitHub
git log --oneline          # list commits
npm install                # install packages for all workspaces
npm run lint               # ESLint bug check
npm run format             # Prettier auto-format
npm run format:check       # check formatting without changing files
```
